# 视频工坊 v2 · 设计简报（给设计和实现用）

## 这是什么

DeepSeek Harness 里的一个 Web UI 插件，产品名仍叫「视频工坊」，但内部彻底换掉：
**只做 Lemo-Opuscar**。旧的 HyperFrames 模板、小说分镜、Remotion/Warm、墨金/纸页/霓虹主题全部删除。

用户是中文创作者。他有一个想法，想做成 30–60 秒的短片：选一种 Lemo 风格，交给 Agent 按风格写渲染代码，自己在工坊里看片、改、渲染、交付。

## 必须理解的产品现实（决定 UI 长什么样）

Lemo 的风格不是主题色板，是**每支片子现写的 canvas / WebGL 绘制代码**。所以工坊不是一个「点一下出图」的生成器，它更像一间**片场**：

1. 选风格（66 种，海报驱动的画廊）
2. 写简报：想法、语言、时长、要不要配音、要不要先看分镜
3. 建组：在磁盘上建项目文件夹，写入 `BRIEF.md` / `project.json`
4. 导演 Agent 写 `TREATMENT.md`（三个结构方案 + 选择 + 镜头表 + 节拍 + 声音）
5. 风格帧：用真实绘制代码抽 3 张静帧（`core/render/still.mjs`），人看，不对就让 Agent 改
6. 分镜（可选）：6–9 张关键帧拼一张 contact sheet，用户点头才继续
7. 声音：配音 → 回读检查 → 配乐 → 混音
8. 成片：`core/render/video.mjs` 渲染 → `mux.sh` 混流/响度 → 播放、版本、交付

工坊的职责是：**让用户始终知道现在到哪一步、看到的是不是真的画面、Agent 在改什么、这一版能不能交。**
不是替 Agent 画画，也不是假装一键生成。

## 三个必须做的界面

### 1. 画廊（默认首页）

- 66 种风格，11 个分类：手绘与绘画、东方传统、印刷与版画、图形与排版、信息与发布、卡通与动画、游戏、电影与时代、材质与 3D、实证影像、剪辑与纪实。
- 每张卡：海报（16:9）、中文名 + 英文名、分类、一句它适合做什么（`lineCn`）、时长参考。
- 海报素材：`design/assets/posters/<slug>.jpg`（1280×720）；数据：`design/assets/styles.json`。
- 需要：分类筛选、搜索（中/英/slug）、hover 有电影感（轻微推近/暗角/信息浮出，别做浮夸 3D）。
- 顶部要能看到「进行中的影片」入口（样例 1–2 部），以及风格库状态（66 种风格 · Lemo 库已连接）。
- 点任意风格 → 进入「新建」。

### 2. 新建（选风格之后的简报页）

- 左侧/上方：所选风格的 hero（海报、中文名、英文名、它是什么、适合什么、参考片长）。
- 表单只要四件事：**想法**（多行，占最大）、**语言**（中文/English）、**时长**（30 / 45 / 60 秒）、**配音**（要/不要）。可折叠的高级项：先看分镜。
- 主按钮：「建组，交给导演」。次按钮：换一个风格。
- 建组后直接进制作台，并显示导演 Agent 的第一条动作（写 Treatment）。

### 3. 制作台（核心）

- 顶部：片名（可改）、风格名、时长、当前阶段、`在 Finder 中显示`、`新渲染`。
- 左侧：六个阶段的竖向进度（简报 / Treatment / 风格帧 / 分镜 / 声音 / 成片），当前阶段高亮，完成态有克制的标记（不要彩色对勾满天飞）。
- 中间：当前阶段的工作区。至少把「风格帧」和「成片」两态做扎实：
  - 风格帧：3 张大图（可点开），显示抽帧时间点、`window.render(t)` 状态、`lint/readcheck` 结果；按钮「重抽帧」「让导演改这一帧」。
  - 成片：大播放器（16:9 黑底，带时间码）、版本列表（草稿/成片/交付）、响度与时长读数、`打开成片`。
- 右侧：导演 Agent 停靠栏。可收合。显示项目上下文（片名/风格/阶段），有阶段相关的快捷动作：
  「写 Treatment」「按 STYLE.md 做 3 张风格帧」「这一帧太灰，改」「按分镜表接时间轴」「检查字幕停留」「渲染草稿」。
  对话要像真的导演沟通，具体、短、带判断，不要客服腔。
- 底部或侧边要有「质检」的落点：readcheck / 响度 / 黑帧 / 字幕遮挡，用文字和数字，不要假图表。

## 样例内容（直接用，别写 lorem）

**风格**：从 `design/assets/styles.json` 里取真实条目。

**Agent 对话样例**（可直接用/改写）：
- 用户：「第二张太灰了，海面看不出层次。」
- 导演：「第 2 帧的问题在纸白被水彩罩染吃掉了。我把远山的罩染降一档、浪尖留白提回来，再抽 3 张。时间轴不动。」
- 用户：「开头三秒不够抓人。」

## 视觉要求

- 像一家独立电影公司的内部工具：编辑感、物质感、克制。不是 SaaS 仪表盘。
- 中文排版是主角：标题可用宋体/思源宋体类的系统字体（Songti SC / STSong），正文 PingFang SC；数字和时间码用等宽（SF Mono / Menlo）。
- 海报是最大的视觉资产：让它们大、完整、有呼吸；不要把小海报塞进小圆角卡片网格里。
- 动效只做「高级感」的三件事：进入的错落、hover 的轻微推近、阶段切换的淡入/位移。不要弹跳、不要发光边框。
- 禁止：紫色渐变、玻璃拟态、emoji、彩色 KPI 卡、假图表、通用圆角卡片墙、英文占位文案。
- 配色要能从 Lemo 的海报里长出来：暗版用近黑 + 暖白 + 一个朱红/琥珀强调；亮版用纸白 + 墨黑 + 一个朱红/靛蓝强调。不要第三种彩色。

## 技术与交付约束

- 单文件 `index.html`（CSS/JS 内联），直接双击能开；图片用相对路径 `../../assets/posters/<slug>.jpg`。
- 不联网、不引 CDN、不装包、不用框架。系统字体。
- 设计基准 1440×900，窗口缩放不能崩；1280 宽也要能看。
- 必须可点：分类筛选、搜索、点海报进新建、建组进制作台、阶段切换、Agent 收起/展开、至少一个「重抽帧」或「渲染」的状态变化。
- 不画浏览器/OS 外框。
- 交付：
  - `design/drafts/<方向名>/index.html`
  - `design/drafts/<方向名>/NOTES.md`：3–5 条设计原则、色板/字号/间距 token、关键交互、实现到 React 时要注意什么、1280 宽的风险。
- 只改自己目录里的文件，别动仓库其他东西。
