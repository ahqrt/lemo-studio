# 纸本片场

方向稿。产品仍叫视频工坊。纸白、墨、一个朱红。像影片目录和场记纸，不是浅色 dashboard。

## 原则

1. 海报是图版，不是卡片。无圆角，图注在图下，编号是目录身份。网格正中一条细线贯穿，分类在左页边，像索引标签。
2. 朱红只留给还不能交的东西：待改的帧、未完成的当前章节、表单没写完。通过的质检用墨色，不用绿色对勾。
3. 片场是档案。六个阶段是编号章节，质检是页脚双线读数，导演是对白记录。不是聊天气泡，不是 KPI 卡。
4. lint 通过和画面能不能交是两件事。第 2 帧可以 `window.render(t)` 有返回、lint 通过，同时批注写着待改。
5. 动效只做三件：目录进入的错落、海报 hover 的轻微推近和暗角、阶段切换的淡入。不弹、不发光。

## Token

色

- 纸 `--paper` `#f6f1e7`，页边和导演栏 `--paper-2` `#efe7d8`
- 墨 `--ink` `#1b1a17`，次级 `#3c3934` / `#6f6a62` / `#9a9388`
- 线 `--rule` `rgba(27,26,23,0.16)`，图版线 `--rule-2` `rgba(27,26,23,0.38)`，标题下用实墨
- 朱红 `--red` `#c8402c`。没有第二彩色

字

- 标题 Songti SC / STSong，正文 PingFang SC，数据 SF Mono / Menlo
- 目录标题 56 / 44，片名 32 / 28，图版中文名 18，正文 14，等宽标签 11
- 中文标题不加粗，靠字号和墨色分层

间距

- 8px 节奏。页边距 36，1360 以下 22
- 目录栏 156 / 124，章节栏 172 / 148，导演栏 304 / 260
- 图版列距 48 / 32。播放器黑底 `#14120f`

## 关键交互

- 左页边筛分类，检索匹配中文、英文、slug、库号。点图版进新建。
- 建组要求写了想法。进制作台后，导演第一条是写 Treatment，约一秒后镜头表落上。
- 片场两部样片可点：《潮水退去之前》停在风格帧，第 2 帧待改；《墙里的邻居》已交付，−14.1 LUFS。
- 章节可切。分镜若简报没要，标「跳过」，仍可补 contact sheet。
- 导演栏可收起。快捷句会改阶段或触发抽帧、渲染。
- 重抽帧：三张变暗，页眉走 `still.mjs · 重抽 n/3`，完了第 2 帧从待改变成待看。点「这一帧可以」才算点头。
- 新渲染：页眉走 `video.mjs` 再 `mux.sh`。有帧没点头就写入草稿，并写明不能交付；都点头了才是成片。
- 成片播放器走 24fps 时间码，可拖进度。版本行可切换当前条。
- 片名可直接改。在 Finder 中显示、打开成片，只在页眉留下路径，不弹窗。

## 做成 React 时

- 不要把图版包成 Card。贯穿细线是网格的事，圆角和阴影会把目录做成卡片墙。
- 阶段切换不要重挂导演栏。输入框的草稿要留在状态里，不然一切阶段就丢字。
- 时间码用一个格式化函数，别在组件里拼字符串。质检从项目状态算，不要另做一套假数据。
- 片名用 blur 提交，不要每个键都写回标题。粘贴进来的换行要去掉。
- 海报 `loading=lazy`，首屏四张除外。路径保持 `assets/posters/<slug>.jpg`。
- 三个界面用路由。制作台是定高分栏，中间和导演各自滚动，不要整页滚。
- 稿里的三张风格帧是海报裁切，用来占版。真产品换 `still.mjs` 的静帧，裁切逻辑删掉。
- 库内编号有空号，最大到 77。稿面用目录序 01–66，库号只在新建页写 `库号`。接数据时不要把两套号混成一个字段。

## 1280 宽

- 图版仍是两列，单张大约 530×300，不会塌成小卡。再窄也不要改成三列。
- 风格帧纵向堆，避免三张并排被挤成邮票。窗口矮于 900 时，工作区内部滚，不要让页脚盖住批注。
- 导演栏 260px，对白会换行。收起是退路，不要在这一档再加第三栏。
- 片单状态不要 `nowrap`，否则「第 2 帧偏灰待改」会被省略号吃掉。
- 播放器宽度按视口高度封顶，为的是「打开成片」和版本表还留在第一屏。顶栏再加高，工作区就会滚。
- 目录栏 124px 刚好放下「手绘与绘画」。不要加图标。
