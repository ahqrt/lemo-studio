# 暗房放映厅

给「视频工坊只做 Lemo」选方向用的静态稿。不是线框。旧 UI 是深色加金色的 dashboard，这稿避开金色，也避开卡片墙。

## 原则

1. 海报是灯，界面是暗房。底色近黑暖炭，海报不加圆角卡片、不加阴影。
2. 朱红只标记「现在」：当前阶段、待改、主按钮、索引进度。不拿来装饰，也不做第二种彩色。
3. 分类是节目册索引，不是筛选胶囊。编号、细线、宋体标题。海报大，留白大，允许不对称和局部裁切。
4. 制作台的中心是一块真正的 16:9。左边阶段像胶片齿孔，时间码等宽。导演坐在旁边，笔记加判断，不是客服气泡。
5. 能不能交，用句子和数字说。质检是 readcheck、响度、黑帧、字幕，不画图表。还不能交，就写原因。

## 关键交互

- 左侧索引筛选分类；检索匹配中文、英文、slug、编号、那一句。
- 点海报进新建。想法预填该画法的真实一句，水彩预填《潮水退去之前》的简报。空着不能建组。
- 「建组，交给导演」进制作台。导演第一条是写 Treatment，约 0.7 秒后三个结构落下来。
- 进行中的两部片直接进制作台：《潮水退去之前》停在风格帧，《墙里的邻居》停在成片。
- 六个阶段可点。风格帧可点开。第 2 帧偏灰，重抽帧后灰度滤镜去掉，笔记和导演口吻一起变。
- 第 2 帧还灰着时，「新渲染」会被导演拦住。改完才写出草稿，并切到成片。
- 已交付的片子再渲染，另开一版草稿，不动 v4。
- 导演栏可收起。快捷动作和输入都会改阶段或追加一句判断。
- 「在 Finder 中显示」「打开成片」只改状态行，不弹假系统窗。

## 做成 React 时

- 画廊和制作台拆开。检索、对话、阶段切换不能重挂 66 张海报。
- 阶段是状态机。路由只负责深链（稿子用了 `#new/<slug>`、`#desk/<id>`），抽帧和渲染的过渡不要放进路由。
- 导演栏收起是布局，不要卸载对话。
- 风格帧必须接 `core/render/still.mjs` 的真图。稿子用海报裁切加灰度滤镜代替，见 `index.html` 里的 shortcut。
- 质检保持文字和数字。不要做成图表组件。
- Windows 没有 Songti SC，会掉到 SimSun，标题行高会变。标题留两行，不要按 Mac 的字面写死高度。
- 建组写入的是 `BRIEF.md` / `project.json`。界面不要假装已经渲染出片。

## 1280

1440 和 1280 都截过，主路径没有横向溢出。剩下的风险：

- 齿孔栏 + 导演栏 + 16:9 同时在，画面宽大约 860。再窄就先收导演栏，不要挤银幕。
- 索引 11 项加检索，900 高能放下。系统字号放大时，索引自己滚，不要把海报顶出视口。
- 长英文名会在半栏字幕里折行。中文名不省略。
- 进行中那一行在 1280 仍是一行。状态文案再长就会挤「打开」，那时让状态换行，不要截片名。
